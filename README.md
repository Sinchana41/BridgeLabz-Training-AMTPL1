# NUnit – Basic Operations

##  Overview
This project demonstrates the **basic usage of NUnit** for writing and executing **unit tests in C#**.  

##  Topics Covered
###  NUnit Attributes
- `[TestFixture]` – Defines a test class
- `[Test]` – Defines a test method
- `[SetUp]` – Runs before each test
- `[TearDown]` – Runs after each test
- `[OneTimeSetUp]` – Runs once before all tests
- `[OneTimeTearDown]` – Runs once after all tests
###  Assertions
- `Assert.AreEqual`
- `Assert.IsTrue`
- `Assert.IsFalse`
- `Assert.IsNull`
- `Assert.IsNotNull`
- `Assert.That` (Constraint-based assertions)

##  Technologies Used
- C#
- .NET
- NUnit Framework
