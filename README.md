## OOPs Concepts Covered
# 1. Encapsulation

Data hiding using private fields

Controlled access using public methods / properties

Improves security and maintainability

 # 2. Inheritance

Code reusability using parent–child relationship

Implemented using : operator

# 3. Polymorphism

Method overloading (compile-time polymorphism)

Method overriding using virtual and override (run-time polymorphism)

# 4. Abstraction (Abstract Class)

Partial abstraction

Abstract methods with implementation in derived classes

# 5. Abstraction (Interface)

Full abstraction

Supports multiple inheritance

# Technologies Used

Programming Language: C#

Framework: .NET 8

IDE: Visual Studio

Learn and apply OOP concepts

Write clean, modular, and reusable code

Improve problem-solving skills

Prepare for technical interviews
